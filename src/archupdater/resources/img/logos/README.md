Generic counter-card icons created specifically for ArchUpdater.

The icons in this directory are original project artwork and are distributed under the same
`GPL-3.0-or-later` license as ArchUpdater. They intentionally avoid third-party logos and trademarks:

- `system.svg`: generic package/cube symbol.
- `aur.svg`: generic build/hammer symbol.
- `flatpak.svg`: generic layered application symbol.
- `plasma_widgets.svg`: generic widget/puzzle symbol.
- `firmware.svg`: generic integrated-circuit symbol.
